Сюда можно класть свои наборы признаков.

Каждый файл .py из этой папки подключается автоматически при расчёте.
Файлы, имя которых начинается с подчёркивания, пропускаются —
так можно временно отключить набор, переименовав его в _имя.py

Образец — в файле example_gradient.py.txt рядом. Чтобы попробовать,
переименуйте его в example_gradient.py и запустите расчёт: в списке
признаков появится Gradient.
